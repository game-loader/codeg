# 机器面板与对话引用

侧边栏的「机器」入口会列出当前 Codeg 后端所在 Tailscale 网络中的设备，包括本机。搜索支持名称、操作系统和 Tailscale 地址。点击设备后，通过 SSH 采集一次只读快照，包含操作系统、架构、CPU、内存、根磁盘、负载、运行时间，以及可用时的 NVIDIA GPU 信息。Linux 和 macOS 支持硬件探针；缺失的命令或指标显示为不可用。

「在线」来自 Tailscale，不能代表 SSH 登录成功。SSH 失败会单独显示错误。可以手动刷新，或勾选每 30 秒刷新；关闭面板或隐藏浏览器标签页后不再定时发起请求。快照带采集时间，不保存监控历史。

在对话输入框中输入 `/machine`，选择该命令（点击或按 Enter），然后选择机器。确认「插入对话」会将机器基本信息和本次探针结果加入可编辑的草稿，发送后代理才能看到这些数据。取消选择不会改动草稿。探针失败时仍可引用基本信息，草稿会明确附带错误；没有获得的硬件信息不会被补造。

## 运行条件

- **桌面模式**：运行 Codeg 的系统用户能执行 `tailscale status --json` 和 `ssh`，且已登录 Tailscale。
- **服务器／Docker 模式**：发现和 SSH 都在服务端运行，服务端需安装 Tailscale CLI 和 OpenSSH 客户端，并能访问 tailscaled、对应网络和 SSH 配置；仅浏览器所在电脑能访问 Tailscale 不够。镜像不会自动安装或登录 Tailscale。
- SSH 使用现有的免交互认证和 `~/.ssh/config`，默认沿用 SSH 的用户名。可以在详情中填写单机用户名并点击探测；此设置只保存在当前浏览器／桌面窗口存储中，按远程连接区分。
- 首次连接需能完成 SSH 主机身份验证；主机密钥变更、权限不足、Tailscale 未登录、缺少命令或连接超时都会显示错误，不会弹出密码输入框。
- 功能只执行固定的状态采集脚本，不安装常驻代理，不执行用户输入的远程命令。后续运维／实验操作由对话中使用的编码代理按你的请求进行。
