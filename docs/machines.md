# 机器面板与对话引用

侧边栏的「机器」入口会列出当前 Codeg 后端所在 Tailscale 网络中的设备，包括本机，以及手动添加的 SSH 机器。搜索支持名称、操作系统和 IP 地址。点击设备后，通过 SSH 采集一次只读快照，包含操作系统、架构、CPU、内存、根磁盘、负载、运行时间，以及可用时的 NVIDIA GPU 信息。Linux 和 macOS 支持硬件探针；缺失的命令或指标显示为不可用。

Tailscale 设备的「在线」来自 Tailscale，不能代表 SSH 登录成功。手动添加的机器在探测前状态未知，详情显示本次 SSH 连接结果。SSH 失败会单独显示错误。可以手动刷新，或勾选每 30 秒刷新；关闭面板或隐藏浏览器标签页后不再定时发起请求。快照带采集时间，不保存监控历史。

在对话输入框中输入 `/machine`，选择该命令（点击或按 Enter），然后选择机器。确认「插入对话」会将机器基本信息和本次探针结果加入可编辑的草稿，发送后代理才能看到这些数据。取消选择不会改动草稿。探针失败时仍可引用基本信息，草稿会明确附带错误；没有获得的硬件信息不会被补造。

## 临时算力机器

点击「新增机器」，填写名称、主机名或 IPv4／IPv6 地址、SSH 端口（默认 22）和用户名（默认 root），选择密码或私钥认证后保存。私钥支持粘贴内容或导入本机的 OpenSSH／PEM 私钥文件（最多 64 KiB），加密私钥需填写口令；不接受公钥或文件路径。无需让该机器加入 Tailscale；即使 Tailscale 发现失败，仍能管理和探测手动添加的机器。连接从当前 Codeg 后端发起，因此后端必须能访问目标地址，或通过配置的跳板机访问目标。

勾选「使用跳板机」后，填写跳板机地址、端口、用户名和认证方式。目标机与跳板机可以分别使用密码、私钥或带口令的私钥，两端凭据独立。支持单层跳板；目标主机名由跳板机解析，跳板机需允许 SSH TCP 转发。保存后选择机器即可检查。macOS 远端工作区和 iOS／网页都使用当前连接的后端执行检查，导入的私钥内容也会保存到该后端。

在机器详情中点击「编辑机器」可更新连接参数。密码、私钥和口令都不会回填；留空会保留原凭据。切换认证方式需提供新的密码或私钥；替换私钥时口令也随之重置，加密私钥需重新填写口令。更换跳板机地址、端口或用户名需重新提供它的凭据，取消跳板机后保存会移除对应凭据。点击「移除机器」并确认后，仅移除 Codeg 中的记录和保存的凭据，不会关机、释放算力实例或停止供应商计费。

连接参数保存在当前 Codeg 后端的数据库中，重启后仍保留。密码、私钥和口令使用项目已有的凭据存储：桌面版使用系统钥匙串，服务器版使用仅服务用户可读写的 `tokens.json`（Unix 权限 0600，内容未加密）。凭据不存入浏览器 localStorage，也不返回到机器列表或插入对话。通过 `/machine` 引用时会包含 IP、端口和用户名，有跳板时还包含跳板机连接信息，但代理不会因此获得登录凭据。

## 运行条件

- **桌面模式**：运行 Codeg 的系统用户能执行 OpenSSH 客户端 `ssh`。Tailscale 自动发现还需要能执行 `tailscale status --json`，且已登录 Tailscale。
- **服务器／Docker 模式**：发现和 SSH 都在服务端运行，服务端需安装 OpenSSH 客户端并能访问目标地址。Tailscale 自动发现还需安装 Tailscale CLI，并能访问 tailscaled 和对应网络；仅浏览器所在电脑能访问 Tailscale 不够。镜像不会自动安装或登录 Tailscale。
- Tailscale 机器使用现有的免交互认证和 `~/.ssh/config`，默认沿用 SSH 的用户名。可以在详情中填写单机用户名并点击探测；此设置只保存在当前浏览器／桌面窗口存储中，按远程连接区分。手动机器使用保存的用户名、端口、认证方式和可选跳板机。
- 手动机器按保存的配置连接，不读取 `~/.ssh/config` 中的代理跳转、转发或其他自定义选项；私钥认证也不会尝试后端 SSH agent 中的其他密钥。Tailscale 机器仍沿用原有 SSH 配置；未实际确认的配置端口不会作为默认值注入对话。
- 密码和私钥口令通过 Codeg 自身提供的 SSH_ASKPASS 辅助进程提供，无需安装 `sshpass`。密码和口令不会放入命令参数或临时文件。私钥仅在检查期间写入临时目录（Unix 目录权限 0700、私钥文件 0600），检查完成、失败或任务取消后删除。Unix 上检查超时或取消会清理 SSH 及跳板子进程。
- 首次连接接受新主机密钥并记录到 known_hosts；已有主机密钥变更时拒绝连接。权限不足、缺少命令或连接超时都会显示错误，不会弹出交互式 SSH 密码提示框。
- 功能只执行固定的状态采集脚本，不安装常驻代理，不执行用户输入的远程命令。后续运维／实验操作由对话中使用的编码代理按你的请求进行。
