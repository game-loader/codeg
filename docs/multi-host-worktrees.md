# 在一个窗口使用多台机器

Codeg 桌面工作区可以同时连接本机和多台 Codeg Server。每台机器仍保存自己的文件、Git 仓库、智能体进程和会话；桌面窗口将它们放在同一个机器列表中。

## 添加机器与仓库

从机器列表的「管理连接」添加服务器地址、令牌和可选请求头。已有远程连接会出现在同一个窗口中。

在目标机器旁点击「打开仓库」，选择该机器上的目录。目录浏览和打开操作使用目标机器的后端，不要求客户端能访问服务器的文件路径。

点击仓库或工作树可以打开其会话。标签显示机器名称，因此两台机器上的同名文件、仓库和会话可以区分。

## 管理工作树

点击仓库旁的工作树按钮，查看该仓库的所有 Git worktree，包括主工作树、分离 HEAD、锁定和可清理条目。

「新建工作树」固定使用对话框中显示的机器与仓库，可以指定新分支、基础分支或提交，以及该机器上的目录。创建之后，Codeg 将目录加入对应机器的工作区。若 Git 创建成功而加入工作区失败，点击「重试加入工作区」即可恢复，无需重复创建分支。

移除操作显示目标机器和目录。默认保留未提交文件及未合并分支的保护；需要时可明确选择同时删除分支或强制移除。主工作树、当前正在操作的工作树、锁定工作树和运行中任务占用的工作树仍受保护。

完整列表和按路径移除接口需要部署包含本功能的 Codeg Server。旧服务器可继续使用已有会话与目录；更新服务器后可使用新增工作树管理接口。

## 跨机器分屏与后台任务

选择跨机器分屏后，为另一侧选择机器。文件、Git、终端和智能体操作始终跟随各自视图的机器；切换到另一台机器不会转移正在执行的命令。

隐藏视图保留会话与任务的订阅。某台机器暂时离线或令牌失效时，其状态会显示在机器列表中，其他机器仍可操作。重新连接会恢复同一后端的状态；将连接地址改为另一个服务器时，Codeg 会重新加载资源，避免复用旧服务器的编号。

窗口布局按机器保存，不保存连接令牌。浏览器直接访问单个 Codeg Server 和现有独立远程窗口继续使用原有单后端流程。

首版沿用 Codeg Server 连接。直接通过 SSH 自动准备远端运行环境不包含在此连接方式中。

## 配置变化与未保存内容

操作弹窗会绑定打开时的连接配置。服务器地址或凭据变化后，旧提交、合并、暂存和推送窗口不会自动切换到新目标；请关闭旧窗口后重新打开。

连接更换或移除时，尚未保存的文件、保存失败的内容和未发送草稿会保留为只读恢复记录，标明原机器、地址和路径，可复制或导出。恢复内容不会自动写入新服务器。若设备存储被禁止或已满，界面会提示在关闭或刷新前先导出。

如果工作树已移除但未合并分支的删除被 Git 拒绝，列表会刷新，并提供单独的分支清理重试；强制删除仍需明确选择，不会自动升级为强制操作。
