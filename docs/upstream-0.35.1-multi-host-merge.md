# v0.35.1 与多机器工作区合并

将此前已经验证的定制版 v0.35.1 合并提交 `75037168`（官方标签 `e21eb6b3`）与多机器分支 `36b0a27d` 合并。两份历史均保留，不使用覆盖式取舍；原工作目录和未提交文件不参与合并。

## 保留并整合

- 官方 v0.35.1：会话标签、按 agent 启用 UI Render、图表、浏览器设备模拟、断线与窗口恢复、终端输出恢复、会话错误与加载改进。
- 定制功能：Zotero 学术工作区、Bark、SSH/Tailscale 机器、文件预览、Codex steering 兼容及 fork writer 回收。
- 当前多机器工作区：单窗口运行时与分屏、统一项目和跨机器/worktree 历史、按机器折叠的无文件夹聊天、原机器/连接代次/路径归属、显式工具与委托位置。

标签定义、标签操作与管理弹窗使用发起方运行时，不能因切换机器而读写其他后端。命令记忆按机器和配置版本隔离；新 UI Render 设置、目录创建和终端停止也使用固定后端。连接代理同时保留配置版本隔离和官方超时、心跳及恢复机制。数据库保留会话标签及连接版本两个迁移，并覆盖从两种已有分支升级。

统一侧栏的标签筛选先选择所属机器，再选择标签，支持任一/全部匹配。相同数字标签 ID 不会跨机器或连接代次命中；删除标签或更换连接配置后会清理失效的筛选条件。隐藏机器首次打开历史会话时延迟加载及连接，显示后恢复原会话 ID；已有后台会话与终端继续保留。
