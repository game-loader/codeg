# 视频预览

在文件树或文件链接中点击视频，即可在文件面板或手机文件抽屉中预览。
播放器提供播放/暂停、进度拖动、音量和系统支持的全屏控件；不会自动播放。
iOS 使用内联播放，也可通过系统播放器进入全屏。

## 连接方式

- Server 网页和 iOS Safari：通过当前服务器的 HTTP 视频接口读取。
- macOS 客户端远端工作区：通过 Rust 转发到本机回环地址，支持远端
  HTTP/HTTPS 服务器及连接配置中的自定义请求头。
- 本地桌面工作区：同一个回环服务读取本地文件。

客户端和远端 Server 都需要更新到包含此功能的版本。
视频按需分段读取，不受图片/PDF 的 base64 大小上限限制。
播放器关闭、切换文件或重试时，会释放对应的访问凭证。

## 格式与编码

识别 MP4、M4V、MOV、WebM、OGV/OGG、MKV、AVI、MPEG/MPG、3GP、3G2。
实际播放能力取决于浏览器和操作系统的解码器；本功能不转码。
跨 macOS、iOS 和其他浏览器分享时，推荐 H.264 视频 + AAC 音频的 MP4。
不支持的编码会显示提示，并允许重试。

## 实机验收

1. 在启用认证的 Server 上放置一个 H.264/AAC MP4，分别用网页、iOS
   Safari 和 macOS 远端工作区点击文件。
2. 确认画面、声音、拖动到尚未加载的位置、全屏以及退出全屏正常。
3. 在 macOS 远端工作区分别验证 HTTP 和 HTTPS；视频路径含中文、空格、
   `#` 时也应可播放。
4. 播放中关闭预览或切换文件，确认声音停止；删除文件或断开网络后，
   确认出现错误提示，恢复后可重试。
5. 打开超过原图片预览大小限制的视频，确认无需下载完整文件即可播放。

自动化覆盖 GET/HEAD、Safari 的 `bytes=0-1` 探测、进度范围请求、416、
凭证撤销和过期、远端转发、移动端渲染入口、关闭清理及错误重试。
自动化不替代 macOS/iOS 的系统解码与全屏实机验证。
